# u0 — euid=0 提升工具（rootd 环境配套）

> 2026-08-18。用途：在 rootd（euid=2000 + 全 caps）环境下把进程 euid 提升到 0，
> 用于访问需要真 root（uid=0）的接口（/proc/vrp、/sys/module 等）。

## 一、背景

- rootd（exploit 的文件队列 daemon）执行命令时保持 **euid=2000 + CapEff 全开**
- 全 caps 能通过 DAC 检查（CAP_DAC_OVERRIDE），但**部分内核驱动/接口检查 `current_euid()==0`**（如 /proc/vrp 的 open 处理器）→ EPERM
- u0 利用 rootd 环境的 **CAP_SETUID** 执行 `setuid(0)`，获得真 root

## 二、实测结论（2026-08-18）

| 项目 | 结果 |
|---|---|
| `u0 id` | ✅ `uid=0(root) gid=0(root)` — setuid(0) 成功 |
| **vr.ko 反应** | ✅ **未触发 fatal**（rootd 主进程本身 uid=0 一直存活，uid=0 进程不在 vr.ko 击杀名单） |
| `/proc/vrp` 读写（uid=0） | ❌ 仍 EPERM（vrp 驱动 open 处理器有**主动权限检查**，非 DAC/SELinux——待逆向确认检查条件） |
| `insmod`（uid=0） | ❌ 仍导致设备重启（模块加载检测不看调用者 uid） |
| vr.ko 文件提取 | ❌ 设备文件系统不存在（/vendor/lib/modules 假目录 ENOENT；/vendor_dlkm 无 vr.ko；全盘 find 无）→ 需内存提取 |

## 三、编译方法

```bash
# WSL Ubuntu (已装 gcc-aarch64-linux-gnu)
aarch64-linux-gnu-gcc -static -O2 -o u0 u0.c
```

## 四、用法

```powershell
# 推送
adb push u0 /data/local/tmp/u0
adb shell "chmod 755 /data/local/tmp/u0"

# 通过 rootc 调用 (rootd 环境 -> u0 -> euid=0 执行)
# PowerShell 中:
$cmd = '/data/local/tmp/u0 /system/bin/sh -c "id; 你的命令"'
$b64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($cmd))
adb shell "/data/local/tmp/rootc B64:$b64"
```

注意：`u0` 的 execv 需要**绝对路径**（`u0 /system/bin/sh -c "..."`；直接 `u0 id` 会失败）。

## 五、源码

```c
// u0.c - setuid(0) 提升工具 (rootd 全 caps 环境使用)
#include <unistd.h>
#include <stdio.h>

int main(int argc, char** argv) {
    if (setgid(0) != 0) { perror("setgid"); return 1; }
    if (setuid(0) != 0) { perror("setuid"); return 1; }
    if (argc < 2) {
        char* args[] = {"/system/bin/sh", NULL};
        execv("/system/bin/sh", args);
        perror("execv sh");
        return 1;
    }
    execv(argv[1], &argv[1]);
    perror("execv");
    return 1;
}
```

## 六、配套：shim.so（LD_PRELOAD kptr_restrict 重定向）

- 用途：ksud insmod 时 ksuinit 会写 `/proc/sys/kernel/kptr_restrict`（rootd euid=2000 环境写被内核 euid 检查拒绝）→ shim 把该路径的 open 重定向到 `/data/local/tmp/fake_kptr`（可写文件），真实 kptr_restrict 保持不变（=0 地址可见）
- 用法：`export LD_PRELOAD=/data/local/tmp/shim.so; ksud insmod ...`（必须同一条命令内 export）
- 编译：`clang --target=aarch64-linux-gnu -shared -fPIC -O2 -nostdlib -fno-builtin -o shim.so shim.c`
