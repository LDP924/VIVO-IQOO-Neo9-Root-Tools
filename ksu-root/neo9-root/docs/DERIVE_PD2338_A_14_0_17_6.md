## 2. 结论：全部常量与 14.0.17.2 逐项相同

|---|---|
| 11 个关键符号 VA（`_stext`/vhangup/`prepare_kernel_cred`/`commit_creds`/`selinux_state`/`swapper_pg_dir`/`init_task`/`init_cred`/`cap_bprm_creds_from_file`/`kptr_restrict`/`kprobe_dispatcher`） | 与 17.2 **逐项相同**（vmlinux-to-elf 重建，基址 `ffffffc008000000`） |

| IKCONFIG | 与 17.2 **逐字节相同**（diff = 0 行）—— 布局级旁证 |
| `_stext` 前 6 字 | `d503233f d10203ff f800865e a9027bfd 910083fd a9036ffc`（与 17.2 逐字相同） |
| vr.ko（vendor_boot ramdisk） | md5 `e679cf933221f3cb1cf81fc903dfbd70`，build-id `eb16270e…`；与 17.2 的 vr.ko（md5 `87cfed37…`）**仅差 38 B**：vermagic 串 18 B + build-id 20 B，**`.text` 全段零差异** ⇒ `VR_DETECT_OFFSET=0x2ecc` 沿用 |
| `cap_bprm_creds_from_file` 序言 | `paciasp; sub sp,sp,#0x90`（= `CAP_BPRM_ORIGINAL 0xd10243ffd503233f`）⇒ `CAP_BPRM_PA=0xa893937c` 沿用 |
| `/system/bin/init` | **与 17.2 的逐字节相同**（sha256 `b3f8d7ca4492110b54093e2182a0e603106aeb808bd17482ccd59bd42232b84d`）⇒ init-hook 常量沿用；`init_hook_derive.py --symbol __system_property_update` 全套自检通过 |

**落码方式**：`fw_profile.h` 改为 `#if defined(FW_14_0_17_2) || defined(FW_14_0_17_6)`

`parse_header` 升级为栈式条件求值（支持 `defined(A) || defined(B)` 与 `#ifndef`，
含回归自检：178/17.2 常量表与改前一致）。
